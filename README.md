# Personal Portfolio Website

This repository contains a personal portfolio website created for a course assignment.

## Required Sections
- Personal Statement
- Skills
- Projects

## Publish with GitHub Pages
1. Create a public GitHub repository named `personal-portfolio`.
2. Upload `index.html` and this `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the **main** branch and **/(root)** folder, then click **Save**.
6. GitHub will provide the live website URL.
